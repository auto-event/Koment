Jalur A — Default:
1. Upload CSV → 2. Set komentar → 3. Pilih mode kecepatan → 4. Generate → 5. Copy Player → 6. Paste Tampermonkey → 7. PLAY

Jalur B — Dengan rekam:
1. Copy Recorder → Paste Tampermonkey → Save
2. Buka YouTube → tap kolom chat → STOP → Copy Steps
3. Paste JSON ke Step 1 → Upload CSV → Generate → Copy Player
4. Paste Player ke Tampermonkey (script baru) → Save → PLAY
⚠️ Untuk HP: jangan lock layar, jangan switch app selama PLAY. Colok charger kalau >200 pesan.
⚠️ Anti-deteksi: pakai komentar bervariasi (pakai {title}), delay ≥ 5 detik, jangan spam promosi.
