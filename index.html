1 JHYT RECORDER (Opsional)

🎙️ JHYT RECORDER v1
Userscript untuk rekam aksi manual di YouTube live chat. Install ke Tampermonkey, buka YouTube, tap RECORD, lakukan aksi manual (tap kolom chat → ketik → tap Send), lalu STOP.
Langkah: 1 Klik Copy Recorder
2 Buka Tampermonkey → Buat skrip baru → Paste → Save
3 Buka YouTube live chat → panel 🎙️ JHYT REC muncul → klik RECORD
4 Tap kolom chat → ketik "test" → tap Send → klik STOP
5 Klik Copy Steps di panel recorder
6 Paste JSON di field di bawah ini
Kosongkan untuk pakai default (tested di HP & desktop). Isi hanya kalau default gagal karena YouTube ubah UI.

5 Generate Player Script

? Alur Lengkap

Jalur A — Default (tanpa rekam):
1. Upload CSV → 2. Set komentar → 3. Generate → 4. Copy Player → 5. Paste Tampermonkey → 6. PLAY

Jalur B — Dengan rekam (kalau default gagal):
1. Copy Recorder → Paste Tampermonkey
2. Rekam di YouTube (RECORD → tap → STOP)
3. Copy JSON → Paste ke Step 1
4. Upload CSV → Set komentar → Generate → Copy Player
5. Paste Player ke Tampermonkey → Save → PLAY
⚠️ Untuk HP: jangan lock layar, jangan switch app selama PLAY. Colok charger kalau >200 pesan.
